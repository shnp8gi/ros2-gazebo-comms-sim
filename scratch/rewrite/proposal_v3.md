## 0. 数値の定義（先に確定）

主結果は次の形で書く。**定義を混ぜない。全パーセントは走行ごと相対差で統一する。**

> 対差 **+3,574 MB**（95%CI **±169 MB**、Wilcoxon 符号順位検定 p = 7.6e-10）、
> 走行ごと相対差 **+15.0%**。**50 走行すべてで提案手法が上回り、最も差が小さい走行でも +8.2%**（最大 +22.2%）。
> 理想反応型への到達率 **78.5%**（走行ごとの範囲も併記する）。

- CI は対差の t 区間（`paired.csv` の `diff_ci95`）。正規近似は使わない
- パーセントに絶対量の CI を付けない
- 天井（oracle）も走行ごと相対差で書く（+19.2%）。v2 で設けた「天井だけ平均比」の例外は**撤回**

### 走行の選定（本文に明記する）

50 走行を記録し、**記録の書き出しが打ち切られた走行**と**走り出しから 35 秒の評価窓を確保できない走行**を除外。
不足分を同じ生成規則で seed を延長して補い、**seed の昇順で先頭 50 走行**を用いた。

- 記録 54 走行 → 有効 52 走行 → 採用 50 走行（seed 12345〜63345）
- 除外: `seed_19345`（窓 18.8 s）、`seed_59345`（書き出し打ち切り）
- 判定は `tools/verify_recording.py --duration 35` による機械検査
- 除外理由はいずれも記録側の事情であり、記録は全手法で共有されるため**手法の優劣に対して選択的でない**

## 2. KF の記載を完全に削除する

**手法の説明に Kalman filter を一切出さない。** 実装がやっているのは RBF 基底によるベイズ線形回帰
（再帰最小二乗）＋残差クリギングであり、その言葉だけで完結して書ける。

| 箇所 | 置き換え |
|---|---|
| σ の合成 φᵀPφ | **P は「係数の共分散行列」**として定義（ベイズ線形回帰の事後共分散） |
| 付表1 の Λ = I | 削除。「係数は走行をまたいでそのまま保持する」と書けば足りる |
| 付表1 の Q = 1e-4 | 「観測間で共分散にごく小さい膨張項を加える」 |
| 付表1 の P₀ = 100 | 「係数の事前分散」 |
| アーム `kkf_frozen` | `rem_frozen`「走行内で地図を更新しない構成」 |

**参考文献**: [1] Kalman、[3] Mardia、[4] Cressie & Johannesson を削除。**[2] Cressie と [5] IEEE 802.15.3e の 2 件が残る**。
基底展開＋空間相関を持つ残差という分解は Cressie の枠内で書ける。

## 3. 論旨の書き換えが必要な 4 箇所

「数値差し替え」では済まない。

### 4.5 公平性 — 主張を弱める

| 手法 | 最小車両の配信量 | 0 MB 車両の割合 |
|---|---|---|
| 提案手法 | 28.7 MB | **1.76%** |
| oracle | 27.6 MB | 1.76% |
| 受動接続 | 9.9 MB | 3.55% |

旧版の「**提案手法だけが 0.00%**」は成立しない。書ける主張は
「最も恵まれない車両の配信量で受動接続の 2.9 倍、0 MB 車両の割合も 3.55% → 1.76% に減る」まで。

### 旧 5-3（oracle は絶対的上界ではない）— 根拠が消滅

旧版はこの主張の**唯一の実証根拠**を「公平性の指標で提案手法が oracle を上回る」に置いていた。
新データでは提案手法 28.7 MB 対 oracle 27.6 MB、0 MB 車両は同率で、**差は有意でない**。
根拠を差し替える: **先読み段数を 1 に固定していること**を明記し、地図は位置の関数なので
未来位置を引けば oracle（現在値のみ既知）を超えうる、という論理で立てる。

### 4.3 の解釈文 — 前提が変わった

旧版 2.5 節の「σν² の寄与が小さいのは、外しても残差場の定数 4 dB が床として残るから」は、
σν² が機構中最大（9.7%）になった今**不要。削除する**。二重計上の事実記述は残す。

### 4.4 の解釈文 — σ の位置づけが逆転

旧版は「σ の寄与は 0.8% にとどまるため、主張を支えているのは主に接続可否の判定精度」と書いていた。
新数値では LCB は 4.6%。さらに図L から次が分かる:

- σ は実際の誤差より約 2.4 倍**過大**（z の標準偏差 0.42。旧版は 1.03 で「合っている」としていた）
- しかし σ と |誤差| の**順位相関は 0.85** と高い

したがって「**大きさは合っていないが順序は合っているので、LCB による順位付けは機能する**」と書き分ける。
旧版の一文は削除。

## 4. 第 5 章「限界」

**維持**: 能動的な切替を行う非提案ベースラインが無い／学習環境と評価環境が同一／遅延ゼロ仮定・
学習相のみ全ペア観測／走行中の車両を遮蔽体として扱っていない／ハンドオーバー回数・ping-pong 率・
無接続時間を測っていない

**書き換え**
- 旧 5-1（単点測定）→ **配置の一般性は本版では担保されていない**。旧版の掃引（表9・図7）は
  閾値 −78.5 dBm・車両スポーンの欠落・静止区間の混入という 3 重の交絡があり無効化された。
  再測定は今後の課題（9 条件で 12〜14 時間）。代理証拠として 4.6 節（需要を変えても優位が保たれる）と
  4.1 節（50 走行すべてで優位）を挙げる
- 旧 5-3 → §3 のとおり根拠を差し替え

**新設**
- **走行内の地図更新に寄与がない**（−0.9%、p = 0.23）。場が静的（固定シャドウ場・フェージング無効・
  遮蔽も静止）である以上、時間方向の逐次推定は原理的に働かない。非定常な環境で初めて意味を持つ
- **較正走行を前提とすること**。2.3 節で述べる LCB の反探索性の帰結として、オンライン適応は主張しない。
  地図が悲観的に外した領域は割り当てられず、観測が入らないため永久に修正されない（楽観誤差は
  自己修正、悲観誤差は自己隠蔽）。実測でも係数の **1 割が事前分散のまま**残っている
- **地図が道路端で発散する**。接続可能標本での RMSE は 2.7 dB だが、全標本では 58 dB に達する。
  係数が大きく振動する悪条件であり、運用域では実害が出ていないが、地図の質としては課題
- **選択余地率の定義**。旧版の定義は車両側（この車から何基見えるか）のみ。排他割当が決めているのは
  RSU の帰属であり、RSU 側の競合も併記する
